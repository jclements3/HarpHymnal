How to read

Columns are tonics in circle-of-fifths order (sharps right of C, flats left). Each cell is four braille glyphs encoding the seven pedal positions:

  • cell 1 = D (left col) + C (right col)
  • cell 2 = B (left col) + separator (right col, dots 4-5-6 always on)
  • cell 3 = E (left col) + F (right col)
  • cell 4 = G (left col) + A (right col)

Within each cell: top = flat, middle = natural, bottom = sharp. A trailing * means the column needed an enharmonic respelling (e.g. F3 Locrian under C is unreachable, so it's spelled as C♯).
